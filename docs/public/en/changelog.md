# Changelog

## 1.0 — 2026-09-02

First release.

- Recipe entry and editing: title, servings, tags, ingredients with typed units of measure,
  procedure steps.
- Recipe library with text search, tag filter and ingredient filter, combinable together.
- Four ways to rescale a recipe — by servings, by an ingredient, by factor, by what is in the
  pantry — with warnings when a discrete quantity (eggs, cloves, sachets…) does not round evenly,
  and a dedicated advisory for oven recipes when baking time and temperature do not scale
  proportionally.
- Rescalings can be saved as variants, without ever overwriting the original recipe, with the
  option to set one as the default.
- Sharing a recipe as plain text or as a `.proportion` file; opening a received `.proportion` file
  to import it.
- Backup and restore of the whole library (recipes, tags, ingredients, variants), with a preview
  before writing and a choice between merging and replacing everything.
- Dashboard with library numbers, the recipe to pick back up, the most-cooked recipes, favourites
  and a random suggestion.
- Persistent shopping list, with automatic merging of compatible quantities and per-recipe origin.
- Cooking mode: screen always on, enlarged text, checkable steps, scaled quantities one tap away.
- Favourites with a counter of how many times a recipe has been cooked.
- Interface in Italian and English, following the system language.
